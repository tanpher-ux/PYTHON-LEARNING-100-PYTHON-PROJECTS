## What You'll Build

Categorizes and analyzes personal spending from bank/CSV exports.

## Flow Diagram

```
Bank CSV export -> load into DataFrame -> categorize transactions -> aggregate by category/month -> summary/chart
```

## How to Build It

1. Install: `pip install pandas matplotlib`\n2. Load transaction CSV into a DataFrame\n3. Categorize transactions with keyword rules\n4. Group by category and month with `groupby()`\n5. Visualize monthly spending by category\n6. Flag unusually large transactions
