# Data Visualizations (Matplotlib)

**Category:** [Data Science & Analysis](../README.md) &nbsp;·&nbsp; **Stack:** Matplotlib &nbsp;·&nbsp; **Difficulty:** Beginner

## What You'll Build

A toolkit of reusable chart functions: line, bar, scatter, histogram.

## Flow Diagram

```
DataFrame/array -> matplotlib.pyplot -> figure + axes -> styled chart -> save/show
```

## How to Build It

1. Install: `pip install matplotlib`\n2. Load or generate a dataset\n3. Write functions for each chart type (line, bar, scatter, hist)\n4. Add titles, axis labels, and legends\n5. Style with a consistent theme\n6. Save figures with `plt.savefig()`
