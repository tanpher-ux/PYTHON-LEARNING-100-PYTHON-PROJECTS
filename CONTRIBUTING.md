# Contributing

Thanks for considering a contribution!

## Ways to contribute
- Fix typos or unclear steps in a project `README.md`
- Improve a `starter.py` scaffold (keep it minimal — it's a starting point, not a finished app)
- Submit your own **finished implementation** of a project as `solution.py` alongside the existing `starter.py`
- Suggest a new project for an existing category, or a new category entirely
- Report unclear or outdated dependency lists in `requirements.txt`

## Workflow
1. Fork the repo
2. Create a branch: `git checkout -b add/solution-flask-microblog`
3. Make your changes inside the relevant project folder
4. Test that your code actually runs: `python -m venv venv && pip install -r requirements.txt`
5. Open a pull request describing your change

## Style
- Keep each project folder self-contained — don't add cross-folder imports.
- Match the existing structure: `README.md`, `starter.py`, `requirements.txt`.
- Beginner/Intermediate/Advanced tags should reflect genuine effort level, not personal opinion — if unsure, compare to similar existing projects.
