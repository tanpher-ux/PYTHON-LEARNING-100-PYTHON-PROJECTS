# Web Form Automator

**Category:** [Automation & Scripting](../README.md) &nbsp;·&nbsp; **Stack:** Selenium / Playwright &nbsp;·&nbsp; **Difficulty:** Intermediate

## What You'll Build

Automatically fills and submits repetitive web forms.

## Flow Diagram

```
Script launches browser -> navigates to form -> fills fields -> submits -> verifies confirmation
```

## How to Build It

1. Install: `pip install selenium` (+ a webdriver) or `playwright`\n2. Launch a browser session\n3. Locate form fields by ID/name/CSS selector\n4. Fill fields programmatically and submit\n5. Wait for and verify a confirmation message\n6. Handle multi-step / multi-page forms

## Files in This Folder

- `README.md` — this file
- `starter.py` — a minimal scaffold to build from
- `requirements.txt` — suggested packages to install first
