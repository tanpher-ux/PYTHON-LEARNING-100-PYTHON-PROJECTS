# Flashcard App

**Category:** [Mobile App Development (Kivy)](../README.md) &nbsp;·&nbsp; **Stack:** Kivy &nbsp;·&nbsp; **Difficulty:** Beginner

## What You'll Build

A spaced-repetition flashcard app for studying any subject.

## Flow Diagram

```
Kivy UI (card front/back) -> tap to flip -> mark known/unknown -> reshuffle deck based on results
```

## How to Build It

1. Install: `pip install kivy`\n2. Model a `Flashcard` (question, answer)\n3. Build a card widget that flips on tap\n4. Implement a simple spaced-repetition queue\n5. Let users add their own card decks\n6. Persist decks locally

## Files in This Folder

- `README.md` — this file
- `starter.py` — a minimal scaffold to build from
- `requirements.txt` — suggested packages to install first
