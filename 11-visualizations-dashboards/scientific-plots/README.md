# Scientific Plots

**Category:** [Visualizations & Dashboards](../README.md) &nbsp;·&nbsp; **Stack:** Matplotlib + NumPy &nbsp;·&nbsp; **Difficulty:** Intermediate

## What You'll Build

Publication-quality plots: multi-axis, error bars, annotated figures.

## Flow Diagram

```
Numerical data (NumPy) -> matplotlib figure with subplots -> annotated/styled -> export vector (PDF/SVG)
```

## How to Build It

1. Install: `pip install matplotlib numpy`\n2. Generate/load your numerical data\n3. Use `plt.subplots()` for multi-panel figures\n4. Add error bars with `errorbar()`\n5. Annotate key points with `annotate()`\n6. Export as high-res PDF/SVG for publication
