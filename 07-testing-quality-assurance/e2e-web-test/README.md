# E2E Web Test

**Category:** [Testing & Quality Assurance](../README.md) &nbsp;·&nbsp; **Stack:** Playwright / Selenium &nbsp;·&nbsp; **Difficulty:** Intermediate

## What You'll Build

End-to-end browser tests that simulate real user flows on a website.

## Flow Diagram

```
Test script -> launches browser -> navigates & interacts with page -> asserts expected UI state
```

## How to Build It

1. Install: `pip install playwright` then `playwright install`\n2. Launch a browser with `sync_playwright()`\n3. Navigate to your app's URL\n4. Interact with elements: click, fill, submit\n5. Assert visible text / element states\n6. Run headless in CI

## Files in This Folder

- `README.md` — this file
- `starter.py` — a minimal scaffold to build from
- `requirements.txt` — suggested packages to install first
